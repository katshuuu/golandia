# 5. Тестирование фронтенда

## 5.1 Инструменты автоматизированного тестирования

| Тип | Инструмент | Назначение в Golandia |
|-----|------------|------------------------|
| Unit | **Vitest 1.x** | `validation`, `progressMap`, `profileLessonOrder` |
| Mock | встроенный `vi` | колбэки форм |
| Среда DOM | **jsdom** | компонентные тесты |
| Компонентные | **@testing-library/react** | `ProfileDisplayNameForm` |

Команда: `cd frontend && npm test`

## 5.3 Ввод, редактирование, удаление данных (ГОСТ 34.602-89, § 3.2.4.3)

| Операция | Экран | Валидация |
|----------|-------|-----------|
| Ввод имени | Профиль → поле на студенческой карточке | `validateDisplayName`: 1–48 символов, буквы/цифры/`. _ -` |
| Редактирование кода урока | Главная → практика | autosave в localStorage, синхронная проверка на сервере |
| Загрузка аватара | Профиль → «Добавить фото» | `validateAvatarFile`: только image/*, ≤ 2 МБ |
| Удаление аватара | Профиль → «Удалить фото» | очистка localStorage + PUT профиля |
| Прогресс уроков | localStorage + опционально `PUT /api/users/:id/progress` | отметка после успешной автопроверки |

При ошибке валидации под полем показывается `role="alert"` (см. `ProfilePage.tsx`, класс `student-profile__field-error`).

**Скриншоты для отчёта** (сделайте при работающем `npm run dev`):

1. Профиль с пустым именем → сообщение «Введите имя…»
2. Профиль с загрузкой файла `.txt` → «Загрузите файл изображения…»
3. Урок: неверный вывод → уведомление «Вывод или код не прошли проверку…»

## 5.4 Реакция на ошибки (ГОСТ 19.301-79, § 3.6)

| Ситуация | Поведение системы |
|----------|-------------------|
| Ошибка сети / API | Текст в `OutputPanel` или toast: «Не удалось подключиться к песочнице» |
| Ошибка компиляции Go | stderr в панели вывода, кнопки остаются активны после завершения |
| Ошибка автопроверки | Понятное сообщение с `result.reason` от сервера |
| Сбой localStorage | Fallback `userId: anonymous`, приложение не падает (`try/catch`) |

Устойчивость: React Error Boundary на уровне маршрутов не требуется — критические пути обёрнуты в `try/catch` в хуках (`useLessonSandbox`).
