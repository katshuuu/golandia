# 7. Инструкция по эксплуатации

## 7.1 Назначение системы

**Golandia** — веб-ИС для изучения Go: теория, интерактивный редактор, запуск кода в песочнице, автопроверка заданий, профиль студента, уровни достижений, чат-репетитор (LLM).

## 7.2 Порядок работы

1. Запустить стек: `docker compose up --build` (или backend + frontend + postgres отдельно).
2. Открыть в браузере: **http://localhost:5173**
3. На главной выбрать модуль и урок в боковой панели.
4. Прочитать теорию, при необходимости запустить демо-код.
5. В практике написать код → **Запустить** → **Проверить**.
6. Перейти в **Профиль** (`/profile`) — имя, фото, прогресс, чат.
7. Открыть **Достижения** (`/achievements`) — уровень героя по пройденным модулям.

## 7.3 Меню и навигация

| Элемент | Маршрут | Назначение |
|---------|---------|------------|
| Логотип Golandia | `/` | Главная, курс и уроки |
| Профиль | `/profile` | Карточка студента, прогресс, чат |
| Достижения | `/achievements` | Уровни героя, описание рангов |
| Плавающий чат | на главной / в профиле | Вопросы репетитору по уроку |

## 7.4 Пользовательские интерфейсы (экраны)

| № | Экран | URL | Функции |
|---|-------|-----|---------|
| 1 | Главная / урок | `/` | Оглавление, теория, редактор, вывод, чат |
| 2 | Профиль | `/profile` | Имя, аватар, кольцо прогресса, архив чатов |
| 3 | Достижения | `/achievements` | Портрет героя, уровень, подсказки |

**Скриншоты для отчёта:** сделайте снимки всех трёх экранов при `npm run dev` (рекомендуемое разрешение 1440×900). Примеры состояний:

- главная: урок с открытой практикой и панелью вывода;
- профиль: заполненное имя и аватар;
- достижения: уровень > 0 после прохождения модуля.

## 7.5 Сопровождение

| Задача | Действие |
|--------|----------|
| Резервная копия БД | `./db/backup.sh` |
| Обновление уроков | правка `backend/data/lessons/*.json`, перезапуск backend |
| Ключ OpenAI | `OPENAI_API_KEY` в `backend/.env` |
| Логи backend | stdout контейнера / терминала `go run` |
| Тесты перед сдачей | `go test ./...`, `npm test` |

## 7.6 Требования к окружению

- Docker 24+ (для compose и песочницы)
- Node.js 20+
- Go 1.22+
- PostgreSQL 16 (или сервис `postgres` в compose)
