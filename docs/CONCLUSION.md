# Заключение

В ходе курсовой работы разработана и протестирована информационная система **Golandia** — интерактивный курс по языку программирования Go.

## Соответствие цели и задачам этапа «Анализ»

| Задача анализа | Результат |
|----------------|-----------|
| Разделение клиента и сервера | Реализован распределённый монолит: React (frontend) и Go REST API (backend), обмен JSON |
| Обучающий контент и практика | Модули и уроки из JSON; песочница и автопроверка заданий |
| Учёт пользователя | Профиль и прогресс в PostgreSQL + локальный кэш для офлайн-устойчивости |
| Качество и стандарты | Валидация ввода (ГОСТ 34.602-89), сообщения об ошибках (ГОСТ 19.301-79), модель данных и резервное копирование (ГОСТ 34.201-89) |

## Технические итоги

1. **Паттерны проектирования (≥ 3):** Стратегия (проверка заданий), Фабричный метод (песочница), Репозиторий (PostgreSQL), Фасад (курс) — см. диаграммы в `docs/03-design-patterns.md`.
2. **Тестирование:** автоматические unit-тесты backend (Go) и frontend (Vitest); выводы зафиксированы в `docs/screenshots/`.
3. **База данных:** PostgreSQL с ограничениями, триггерами аудита и скриптом резервного копирования.
4. **Эксплуатация:** документирован порядок запуска, навигация и назначение экранов (`docs/07-manual.md`).

## Вывод

Поставленная цель достигнута: создана работоспособная информационная система, поддерживающая основные бизнес-процессы обучения (изучение теории, выполнение и проверка кода, учёт прогресса, обратная связь через чат). Архитектура соответствует требованию распределённого монолита, обеспечивает приемлемое время отклика для типовых операций и готовность к сопровождению по регламентам ГОСТ.

Дальнейшее развитие: расширение покрытия e2e-тестами (Playwright), вынос прогресса полностью на сервер с авторизацией, мониторинг SLA в production.
